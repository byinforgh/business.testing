    What the sample cannot do

    • Client links only open on this device. The photos are stored in this browser, so a client on another phone sees nothing. A live site fixes this.
    • Logos are added in the browser. A live site adds them on the server, so the original photo never reaches the client.
    • No login. A live site has one owner login for you. Clients need no account.

    How it works on a live website

    You upload once. The server adds the logo, saves three copies, and each client link points to the logo copy only.

    Where it can run

    RecommendedOne small server plus file storage

    A Node server on a low-cost cloud machine, the sharp image library for the logo step, and an S3-compatible bucket such as Cloudflare R2 or Amazon S3 for the files. Simple to understand and easy to move later.

    Managed platform

    Vercel or Netlify for the site, Supabase or S3 for files and database, and a serverless function for the logo step. Less to look after, more moving parts to connect.

    Everything on one machine

    Photos on the server's own disk. Cheapest to start. You must schedule backups yourself, and the disk fills up as shoots add up.
